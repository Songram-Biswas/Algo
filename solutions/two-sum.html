    Given an array of integers nums and an integer target, return the indices of the two numbers that add up to target.

    You may assume exactly one solution exists, and you may not use the same element twice.

    Input: nums = [2,7,11,15], target = 9

    Output: [0,1] // nums[0] + nums[1] == 9

    💡 Secret tricks for spotting complexity fast

    • Count the loops, not the lines. One pass over n elements with O(1) work per element → O(n). Nested loops over the same input → multiply (often O(n²)).
    • Hash map operations are O(1) average. If a loop does one map lookup/insert per iteration, the loop's total time stays O(n) — the map doesn't add a factor.
    • Space tracks "extra" memory, not input. The input array itself doesn't count. Ask: "what new data structure am I building, and how big can it get?" Here, the map can hold up to n entries → O(n) space.
    • Sorting costs O(n log n) — if you see .sort() anywhere, that's usually your time complexity floor unless something else is worse.
    • Two pointers / sliding window ≠ O(n²). Even though it "looks" like two loops, each pointer only moves forward — total work is still O(n).

    A brute-force check of every pair costs O(n²). The interview-standard fix: walk the array once, and at each index ask "have I already seen the number that completes this pair?"

    1. For the current number, compute complement = target - num.
    2. Look up complement in the hash map.
    3. If found, return the stored index and the current index — done in a single pass.
    4. Otherwise, store num → index and continue.
    from typing import List

class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        seen = {}  # value -> index

        for i, num in enumerate(nums):
            complement = target - num

            if complement in seen:
                return [seen[complement], i]

            seen[num] = i

        return []  # no solution found

    Time

    O(n)

    Single pass; each hash map op is O(1) average.

    Space

    O(n)

    Hash map stores up to n entries in the worst case.
